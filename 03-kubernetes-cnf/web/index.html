🔄 HPA - Auto Scaling

apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: sip-proxy-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: cnf-sip-proxy
  minReplicas: 2
  maxReplicas: 10
  metrics:
    - type: Resource
      resource:
        name: cpu
        target:
          type: Utilization
          averageUtilization: 70

🔒 Network Policy

apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-sip-traffic
spec:
  podSelector:
    matchLabels:
      app: sip-proxy
  ingress:
    - from:
        - podSelector:
            matchLabels:
              cnf-type: security
      ports:
        - protocol: UDP
          port: 5060

🛡️ Pod Disruption Budget

apiVersion: policy/v1
kind: PodDisruptionBudget
metadata:
  name: media-gateway-pdb
spec:
  minAvailable: 1
  selector:
    matchLabels:
      app: media-gateway

📋 Commandes de la Démo

docker-compose up -d Démarrer le cluster K3s
docker exec -it k8s-kubectl bash Accéder au terminal kubectl
kubectl get nodes Voir les nodes du cluster
kubectl get pods -n telco-cnf Lister les pods CNF
kubectl get pods -n telco-5g-core Lister les pods 5G Core
kubectl apply -f /manifests/ Déployer tous les manifests
kubectl get hpa -n telco-cnf Voir les HorizontalPodAutoscalers
kubectl describe networkpolicy -n telco-cnf Voir les Network Policies
kubectl scale deployment cnf-sip-proxy -n telco-cnf --replicas=5 Scaler manuellement le SIP Proxy
kubectl rollout status deployment/cnf-sbc -n telco-cnf Suivre un rolling update
