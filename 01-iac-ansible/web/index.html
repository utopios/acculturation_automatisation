📋 Commandes de la Démo

docker-compose up -d Démarrer l'environnement
docker exec -it ansible-controller bash Accéder au contrôleur Ansible
ansible all -m ping Tester la connectivité
ansible-playbook /ansible/playbooks/01-configure-vlans.yml Configurer les VLANs VoIP
ansible-playbook /ansible/playbooks/02-configure-qos.yml Appliquer la QoS Telco
ansible-playbook /ansible/playbooks/03-full-config.yml Déploiement complet
ansible-playbook /ansible/playbooks/04-verify-config.yml Vérifier les configurations
